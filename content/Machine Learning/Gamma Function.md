The gamma function $\Gamma[x]$ is defined as:
$$
\Gamma[x] = \int_{0}^{\infty} t^{x-1} e^{-t} \, dt 
$$
This extends the factorial values so that $\Gamma[x] = (x-1)!$ for $x \in \{ 1,2,\dots \}$.
