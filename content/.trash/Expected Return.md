For a [[Markov Process|Markov decision process]] where we have an agent carrying out actions according to a [[Policy|policy]], we want to choose a policy that maximizes the expected return. How do we make this idea mathematically precise? We assign a value to each state $s_{t}$ and each state-action pair $\{ s_{t}, a_{t} \}$.
