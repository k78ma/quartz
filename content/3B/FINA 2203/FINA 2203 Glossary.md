| Symbol | Term              |
| ------ | ----------------- |
| $r$    | Interest rate     |
| $PV$   | Present value     |
| $FV$   | Future value      |
| $C$    | Cash flow         |
| $n$    | Number of periods |
|        |                   |

## Time Value of Money
Future value of a cash flow:
$$
FV_{n}=C\times(1+r)^{n}
$$
Present value of a cash flow:
$$
PV= \frac{C}{(1+r)^{n}}
$$
