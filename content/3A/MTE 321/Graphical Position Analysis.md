Graphical position analysis is a basic "old-school" position analysis technique, requiring precise, accurate drawing of the links and their positions. Once the drawing is complete, we can measure the angles. A new drawing needs to be created for each position that requires analysis. This method can be useful for a quick, approximate solution for one position.

![[Graphical Position Analysis.png]]

There are two possible solutions (aka circuits) for the four bar linkage. The solution present depends on how the links are connected. 
- Crossed: Two links adjacent to the shortest link cross one another
- Open: Two links adjacent to the shortest link do not cross one another
