1. What is hardware software co-design? What is the closest we have come to it so far?

Hardware software co-design is designing the hardware and software components of a system in parallel, instead of designing hardware first and then software after. The closest we are right now is FPGAs, where changes can be made to the hardware and recompiled before updating the corresponding software.

2. Define the terms.

- Microprocessor: Consists of a CPU only, no main memory or support for I/O devices. Performs all logic and arithmetic operations.
- Microcontroller: Includes a CPU as well as additional components, such as memory and I/O. it can be used as a stand-alone system.
- SoC: Fully functional computer system implemented in a computer chip. Different from a microcontroller because the configuration is chosen by the user.
- SoPC: SoC implemented with high-density, reconfigurable programmable logic devices. The user can reconfigure and program the chip logic.
